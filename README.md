# 今课 Nowledge

一个纯前端的单文件学习工具：打开 `.html` 就能用，无需安装、无需构建、无需后端，数据只保存在您自己的浏览器里。

> **关于开发方式，想先说明一下**
> 本项目是 **AI 辅助开发** 的作品，并非逐行手工写成。功能设想、方案取舍、逐项验收与最终定稿由作者本人负责；代码实现、缺陷排查、资料考据、文案整理等环节，借助了 AI 工具协助完成。我们尽量把每处改动都验证过，但疏漏恐怕仍在所难免，若您发现问题，恳请提 Issue 告知，非常感谢。

## 功能一览

- **科目与作业**：自定义科目、排序、启停；一条作业可拆成多个独立子项，逐条勾选完成
- **日期与历史**：前后翻日、回到今天；每天的重点备忘与名言
- **专注计时**：番茄钟（25/5、45/10、60/15 等预设），支持暂停、重置、跳过与提示音开关
- **教室模式**：隐藏编辑控件，适合投屏讲解；字号与列数会随内容自动重排
- **布局偏好**：`Alt + L` 可记住当前场景的布局
- **分享图**：一键把当天作业重绘成简约 PNG 下载（Canvas 绘制，并非屏幕截图）
- **每日名言**：74 条中英双语，逐条核对过原文与译本
- **其他**：考试倒计时、浅色 / 深色主题、自定义快捷键、数据导入导出
- **AI 助手（可选）**：在设置里填入任意 OpenAI 兼容接口，可用「润色并分点」「单条润色」；支持保存后自动测试连接与 CORS 代理

## 快速开始

直接双击任意一个 `.html` 即可；若您习惯用静态服务器，下面几种方式也都可以：

```bash
python -m http.server 8080
# 或
npx serve .
```

无需 Node 环境、无需构建步骤，也不需要账号登录。

## 关于 AI 功能

AI 是可选能力，不配置也完全不影响其余功能。若您想启用：

1. 打开「设置 → AI 设置」，填写名称、Base URL（通常需含 `/v1`）、模型名与 API Key，保存后会自动测试连接。
2. 认证方式支持 `Authorization: Bearer` 与 `api-key` 两种，可按服务商要求切换。
3. 若浏览器直连出现 `Failed to fetch`，多半是接口未开放跨域。此时可解压 `Nowledge-AI-Proxy.zip`，按包内 `使用说明.txt` 启动本地代理，再把代理地址填入「CORS 代理」即可。代理包内置便携版 Node.js，不必另外安装环境。

有一点想提前说明：API Key 以明文保存在**您自己浏览器的 localStorage** 中，不会上传到本项目或任何第三方；请求只发往您填写的服务商接口。若使用公用电脑，还请留意。代理包内随附 `NODE-LICENSE.txt`。

## 数据与隐私

所有作业、科目与设置都只存在浏览器本地，没有账号体系、没有云同步、也没有统计上报。清理浏览器数据会一并清除，建议您偶尔用「导出数据」留一份备份。

## 技术与版本

单文件 HTML（CSS / JS 全部内嵌）、原生 JavaScript、IIFE 模块化，`localStorage` 持久化，由 `migrate()` 负责向前兼容旧数据。各发布版本基于同一套代码骨架，当前产品版本统一为 **V3**；其中的 `SCHEMA_VERSION = 1` 是数据结构版本，与产品版号无关。

除非您主动启用 AI，否则应用不会产生任何对外网络请求。
