# 今课 Nowledge

纯前端单文件学习工具，零构建、零依赖。打开 `.html` 即可使用，数据保存在浏览器本地。

## 功能

- **科目管理**：添加 / 重命名 / 排序 / 启用或禁用科目
- **任务卡片**：按科目添加卡片，标记完成，昨日任务一键复制
- **日期导航**：上一天 / 下一天 / 返回今天，跨日期查看与记录
- **今日重点**：每天一条备忘，防抖写入
- **专注计时**：番茄钟模式，支持 25/5、45/10、60/15 等预设，暂停 / 重置 / 跳过，提示音开关
- **教室模式**：切换后隐藏操作控件，适合投屏讲解；内容变化后自动重测布局
- **主题切换**：浅色 / 深色两色主题
- **每日名言**：中英文双语，点击切换
- **考试管理**：记录并倒计时考试日期
- **键盘快捷键**：`E` 切换模式 / `F` 进入专注 / `N` 下一天 / `P` 上一天；自定义快捷键可在设置中配置

## 南京师大附中专业版

这是为**南京师范大学附属中学**定制的版本——作者本人就是南师附中的学生。

### 背景

南师附中是百年名校，拥有独特的视觉标识与文化精神。这个版本把学校的品牌元素（校徽、校训）和校园美学深度融入学习工具中，让使用过程更有归属感。

### 特殊性

- **品牌融入**：校徽、校训作为 UI 核心视觉，贯穿 Header、教室模式、专注模式
- **视觉定制**：配色、字体比例、动画节奏贴合附中校园美学
- **功能适配**：针对附中教学节奏与班级管理模式优化布局

如果你也是附中学生，可以直接使用这个版本获得完整的归属感体验。

## 运行方式

```bash
# 直接浏览器打开
open Nowledge.html
# 或用任意静态服务器
npx serve .
# 或 Vite / Python / Node 都行
python -m http.server 8080
```

无需 Node 环境、无需构建、无需后端。

## 技术栈

- 单文件 HTML（CSS + JS 全部内嵌）
- 原生 JavaScript SPA，IIFE 模块化（Store / State / Actions / Renderer / DateEngine / LayoutEngine / ClassroomManager / FocusTimer / Shortcuts / Utils）
- localStorage 持久化，`State.set()` + 防抖 `persist()` 落盘
- Schema 版本化管理，`migrate()` 向前兼容旧数据

## 部署

支持任意静态托管：GitHub Pages / CloudStudio / Vercel / 自建服务器均可，把 `.html` 丢上去就行。

## 本地开发

直接编辑 `.html` 文件，刷新浏览器即可预览。没有构建步骤。
